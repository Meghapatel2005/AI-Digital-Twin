# 🤖 AI Digital Twin
An AI-powered Digital Twin and Predictive Maintenance platform for industrial robotic systems.
The project simulates real-time machine telemetry such as **temperature, vibration, RPM, and machine health**, and uses Machine Learning to predict failure risk and detect abnormal machine conditions.

### ✨ Key Features
- 📊 Real-time machine monitoring
- 🤖 AI-based failure prediction
- 🚨 Intelligent machine alerts
- 📈 Prediction & health analytics
- 🟢🟡🔴 Risk classification
- 🤖 Interactive 3D Digital Twin
- 📜 Live event monitoring

### 🛠️ Tech Stack
**Frontend:** React.js, Vite, Tailwind CSS, Recharts, Three.js  
**Backend:** Python, FastAPI, Uvicorn  
**ML:** Scikit-learn, Joblib

### 🎯 Objective
To combine **AI, Machine Learning, real-time monitoring, and Digital Twin technology** for predictive maintenance of industrial machines.
